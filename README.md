# 4月读书实践周进展
### 4月27日

本日主要完成社会仿真模块的整体结构梳理，并启动数据入口模块的实现。结合现有项目代码，对系统功能进行了重新划分，明确了后续需要完善的五个关键部分：数据读取、实验控制、指标计算、结果可视化以及动态更新机制。

在此基础上，开始编写 data_loader.py，实现对 processed/netizen_science_standardized_profiles.csv 的读取与预处理。在处理过程中发现，原始数据中部分数值字段存在非数字字符和缺失值，直接进行类型转换会导致异常。对此，采用 pandas.to_numeric(..., errors='coerce') 将异常值统一转为 NaN，并使用中位数进行填充，同时对 handle 字段统一为字符串类型，以保证后续处理的稳定性。

整体来看，本阶段重点在于完成数据层的规范化，为后续仿真提供可靠输入。

### 4月28日

本日重点实现实验控制模块及传播网络构建逻辑。新增 experiment_controller.py，将仿真流程由原先的固定逻辑改为配置驱动形式，使实验参数（如种子选择策略、用户筛选条件等）可以灵活调整，并支持多组实验对比。

在种子选择方面，将原有单一逻辑拆分为随机、基于影响力以及基于情绪倾向三种策略，从而为不同实验场景提供支持。

在网络构建过程中，初始实现采用随机连接方式，存在自环及重复边的问题，影响网络结构合理性。对此，在 network_builder.py 中增加约束条件，避免节点指向自身，同时结合用户的 followers 数量控制连接规模，使生成的网络在结构上更接近实际社交关系。

### 4月29日

本日完成指标计算模块与可视化模块的实现。在 metrics.py 中补充了多项用于描述传播过程和结果的指标，包括传播规模、覆盖率、增长率，以及情感均值、立场方差和极化指数等。

在初步测试中发现，仅以数值形式输出指标不利于直观分析传播过程。因此，进一步实现 visualization.py，基于 matplotlib 绘制传播曲线、立场分布图及情感变化图，并支持多实验结果的对比展示。

通过图形化方式，可以更直观地观察传播趋势及不同策略之间的差异，提高了结果分析的效率。

### 4月30日

本日主要完善动态更新机制，并对整体流程进行整合与测试，完成 run.py 的基本实现。

在动态更新部分，引入节点状态随传播过程变化的机制，包括情感向传播者靠拢、立场发生偏移、活跃度随时间衰减以及认知状态的调整。

初期实现中，由于更新规则较为简单，仿真结果变化不明显。随后对更新方式进行了调整：以传播者为主要影响源，并根据其影响力进行加权，同时加入活跃度衰减机制，使节点既能够被激活，也会逐步“退出”传播过程。调整后，整体仿真结果表现出更明显的动态特征。

### 实践总结

经过本周的工作，社会仿真模块已初步形成一个结构完整的实验框架。系统能够实现从数据读取、状态建模，到实验配置、过程模拟，再到指标计算与可视化输出的完整流程。

在技术实现方面，重点完成了数据清洗与标准化、传播网络构建、实验配置化设计、动态状态更新机制以及结果可视化等关键环节。其中，动态更新机制的引入，使模型从静态扩散过程扩展为随时间演化的系统，在一定程度上增强了仿真的现实表达能力。

本周遇到的问题主要集中在数据处理和模型设计两个方面。数据层面需要解决格式不统一和类型混杂的问题；模型层面则需要在简化与真实性之间进行平衡。通过分模块实现、逐步调试以及可视化验证，这些问题均得到较为有效的解决。

总体来看，目前的系统已具备开展基础对比实验的能力，并为后续引入更复杂的用户行为机制和传播模型提供了良好的基础。下一阶段可以进一步优化网络生成方式，并细化传播概率与行为规则，以提升仿真结果的解释力和参考价值。
